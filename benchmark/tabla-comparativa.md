# Labor guidance comparison matrix

**Observed: October 5, 2026.** Tools occupy the rows, including the **Team proposal**, as required by the assignment. Four tables retain ten base dimensions and four domain dimensions; the category provides selection context. **O = observed in nine public screenshots; D = documented in official sources; P = proposed for team validation, with prototyping pending and no approved decisions implied.** Feature priorities reflect relevance to UX personas, not measured usage frequency. Private flows, full accessibility, and data retention were not tested.

DT01–DT03, SU01–SU03, and CA01–CA03 refer to the [annotated images and analysis](README.md). H2/H3/H4/H6/H8/H10 refer to [Nielsen's heuristics](https://www.nngroup.com/articles/ten-usability-heuristics/); their application interprets visible evidence.
